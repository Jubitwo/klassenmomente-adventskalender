    Türchen 1

    Gespeichert

    Für die Klasse veröffentlichen

    Nicht verbunden

    Ziel: Jubitwo/klassenmomente-adventskalender · main. GitHub prüft deine Schreibberechtigung. Veröffentlicht werden alle lokal gespeicherten Inhalte und die Türchenanordnung, nicht das Passwort.

    Einmalig ein GitHub-Token einrichten
    1. In GitHub unter Settings → Developer settings → Personal access tokens → Fine-grained tokens ein neues Token erstellen.
    2. Resource owner: Jubitwo; Repository access: Only select repositories → klassenmomente-adventskalender.
    3. Repository permissions: Contents → Read and write. Kurzes Ablaufdatum wählen. Keine weiteren Schreibrechte nötig.
    4. Token nur unten eingeben, niemals im Chat, in Kalenderinhalten oder im Repository hinterlegen. Weitere Lehrkräfte benötigen eigene GitHub-Schreibrechte und eigene Tokens.
    Token-Einstellungen auf GitHub öffnen ↗

    Das Token bleibt nur im Arbeitsspeicher und wird beim Neuladen, Abmelden oder Trennen verworfen. Es wird ausschließlich an api.github.com gesendet. Nur auf einem vertrauenswürdigen Gerät verwenden.
